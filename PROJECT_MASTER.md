# Software Factory v2 — Project Master

Status: foundation implementation (not production-ready)
Canonical repository: mahdichaoub/software-workflow

## Purpose
Build a lightweight, spec-driven autonomous software factory that converts approved feature requests into tested pull requests with bounded execution and minimal token overhead.

## Authority
- This file is the project navigation index, not a replacement for detailed specs.
- Existing `project/AGENTS.template.md` and `docs/PLAYBOOK.md` remain the starter-kit workflow.
- `docs/CHAMELEON_LESSONS.md` contains prior development lessons.
- `docs/FACTORY_V2_ARCHITECTURE.md` describes the target architecture.
- `docs/FACTORY_V2_ROADMAP.md` defines implementation milestones.
- `factory/contracts/task.schema.json` defines the initial machine-readable task contract.

## Non-negotiables
1. Small independently verifiable feature slices.
2. No execution without the required approvals.
3. Source files modified only in isolated worker environments once execution integration exists.
4. Verification evidence must be generated by tools, not invented by agents.
5. Default to selective context; do not load the full repository on every task.
6. Cap automated repair attempts and spending; escalate when limits are reached.
7. Preserve existing starter-kit behavior until replacement is tested.

## Current milestone
M0: document contracts and integration plan. Next: implement transactional task coordinator and tests, then isolated worker adapter.

## Scope boundary
This branch does not install a running autonomous agent, replace existing Claude hooks, or deploy production services.
